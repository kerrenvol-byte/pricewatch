# 🎯 טוויסטר — מחולל הוראות קולי

עמוד עצמאי (בלי צורך בשרת) שמריץ משחק טוויסטר לבד: כל 7 שניות עולה הוראה חדשה — צבע ("אדום" / "כחול" / "צהוב" / "ירוק") ואיבר ("יד ימין" / "יד שמאל" / "רגל ימין" / "רגל שמאל") — מוצגת על המסך **וגם מוקראת בקול**.

## שפת ההקראה

שלושה מצבים, בבחירה מתוך הדף עצמו (הבחירה נשמרת לפעם הבאה):

| מצב | מה נשמע | מה מוצג |
|---|---|---|
| **עברית** | "יד ימין על אדום" | עברית |
| **English** | "Right hand on Red" | אנגלית |
| **עב + EN** | עברית ומיד אחריה אנגלית | עברית, ומתחתיה שורת האנגלית |

מצב "עב + EN" שימושי כששחקנים לא דוברי עברית משתתפים, וגם כשבמכשיר אין קול עברי מותקן.

## הפעלה

- **Windows:** לחיצה כפולה על `start-twister.bat`.
- **כל מכשיר אחר (כולל טלפון):** פותחים את `index.html` בדפדפן (או מעלים אותו לכל שרת סטטי / GitHub Pages).

אין תלות בחיבור אינטרנט, שרת, או שאר הקבצים בריפו הזה — קובץ ה-HTML עצמאי לחלוטין.

## איך זה עובד

- לחיצה על **▶️ התחלה** מפעילה את הלולאה (הלחיצה גם נדרשת כדי שהדפדפן יאפשר הקראה קולית).
- כל 7 שניות: הוראה אקראית חדשה (בלי לחזור מיד על אותה הוראה), מוצגת עם רקע בצבע המתאים ומוקראת בקול.
- **⏸️ השהיה / ⏹️ עצירה** לשליטה במשחק, **🔊/🔇** להשתקת הקול בלי לעצור את הטיימר.
- החלפת שפה באמצע המשחק מציגה מיד את ההוראה הנוכחית בשפה החדשה, בלי לאפס את הטיימר.
- המסך נשאר דלוק בזמן המשחק (Screen Wake Lock, כשנתמך על ידי הדפדפן).
- בלנדסקייפ בטלפון הפריסה עוברת לשתי עמודות כדי שכל הכפתורים יישארו על המסך בלי גלילה.

דורש דפדפן עם תמיכה ב-Web Speech API (Chrome / Edge / Safari מודרניים) כדי להקריא בקול; אם אין תמיכה, ההוראות עדיין מוצגות על המסך.

## אם לא נשמע קול

השורה התחתונה בדף מדווחת אילו קולות נמצאו במכשיר (למשל `🔊 עברית: Carmit`). אם מופיעה שם אזהרה שאין קול בשפה הנבחרת, אפשר להוריד קול דרך **הגדרות ← נגישות ← תוכן מדובר ← קולות**, או פשוט לעבור לשפה השנייה. באייפון כדאי לוודא גם שמתג ההשתקה הפיזי בצד המכשיר כבוי — הוא משתיק גם הקראה.
