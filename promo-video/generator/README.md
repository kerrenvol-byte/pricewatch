# מחולל הסרטון

שלושה קבצים שמייצרים את הסרטון מקצה לקצה. אין תלות בנכסים חיצוניים — הכל מצויר בקוד.

| קובץ | תפקיד |
|---|---|
| `film.html` | הסרטון עצמו. קנבס 1080×1920 עם `render(t)` שמצייר כל פריים בזמן `t`. 18 השוטים הם הפונקציות `s01`–`s18`. |
| `audio.py` | הפסקול והסאונד דיזיין. מסנתז `score.wav` ב־numpy. |
| `render.py` | מריץ את `film.html` ב־Chromium, מצלם 840 פריימים ומקודד ל‑MP4 עם הפסקול. |

## התקנה

```bash
pip install imageio-ffmpeg numpy playwright
```

Chromium כבר מותקן בסביבה; אם לא — `playwright install chromium`, ואז לעדכן את `CHROME` בראש `render.py`.

## הרצה

```bash
python3 audio.py                                    # → score.wav
python3 render.py promo_9x16.mp4                    # מאסטר 1080×1920
python3 render.py promo_1x1.mp4 --size=1080x1080    # פיד
python3 render.py promo_9x16_silent.mp4 --silent    # בלי סאונד
```

כ־45 שניות לרינדור מלא. הפריימים לא נשמרים לדיסק — הם נכתבים ישירות ל־ffmpeg.

## מה כדאי לשנות

**הלוגו.** ב־`film.html`, בפונקציה `s18`, החליפו את מלבן מציין המקום ואת הכיתוב `הלוגו שלכם` בציור הלוגו שלכם או בתמונה טעונה.

**הכתובת.** באותה פונקציה, `YOURSITE.CO.IL`.

**פריסת המקלדת.** הקבוע `ROWS` בראש הקובץ. שלוש שורות של שמונה אותיות; משמש גם בשוט 11 (החריטה), גם בשוט 12 (החשיפה) וגם ברמז שעל הדסק בשוט 17.

**תזמון.** המערך `CUTS` מגדיר `[התחלה, סוף, פונקציה]` לכל שוט. שינוי שם משנה את הקאט; יש לעדכן בהתאמה את `copy()` ואת `audio.py`.

**טקסט על המסך.** המערך בתוך `copy()` — `[טקסט, כניסה, יציאה, מיקום אנכי כשבר מהגובה]`.

## פונטים

הסביבה כאן לא כללה פונט עברי ייעודי, ולכן הכיתוב מרונדר ב‑DejaVu Sans. להתקנת Heebo או Assistant על המכונה — הכיתוב ישתדרג מיד בלי שינוי קוד, דרך `F()` ב‑`film.html`.
