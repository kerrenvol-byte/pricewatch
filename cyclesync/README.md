# 🌸 CycleSync — מעקב מחזור אישי

אפליקציית ווב אישית למעקב מחזור: יום במחזור, שלב נוכחי (וסת / פוליקולרי / ביוץ / לוטאלי),
חיזוי וסת הבאה, ופידבק יומי על מצב רוח, אנרגיה ותיאבון — עם גרפים שמראים את הדפוסים שלך
לאורך זמן. נגישה מהדפדפן, אפשר להוסיף למסך הבית באייפון ולהשתמש כמו אפליקציה.

## הפעלה

לחיצה כפולה על **`start-cyclesync.bat`** — נפתח דפדפן בכתובת http://localhost:3778
(בפעם הראשונה זה גם מתקין תלויות אוטומטית).

או ידנית:
```bash
npm install
npm start
```

## שימוש מהאייפון

1. ודאי שהמחשב שמריץ את השרת דלוק ובאותה רשת Wi-Fi כמו האייפון
2. גלשי מהאייפון לכתובת של המחשב ברשת (למשל `http://192.168.1.50:3778`)
3. בספארי: כפתור השיתוף ⟵ **"הוספה למסך הבית"** — ותקבלי אייקון אפליקציה עם המסך הפותח

## למה אין חיבור חי לאפליקציית הבריאות?

אפליקציית ווב — גם כזו שמותקנת למסך הבית — לא יכולה לקרוא נתונים מ-HealthKit של אפל.
זו הגבלה של מערכת ההפעלה מטעמי פרטיות רפואית, ולא ניתנת לעקיפה בלי אפליקציה קומפילית
אמיתית (הדורשת Xcode/Mac או חשבון Apple Developer בתשלום).

**במקום זה, יש כאן שתי דרכים להזין נתונים:**

1. **הזנה שוטפת** — סימון יום וסת + פידבק יומי ישירות באפליקציה (לוקח כמה שניות)
2. **ייבוא היסטוריה חד-פעמי** — אפליקציית הבריאות מאפשרת לייצא את כל הנתונים כקובץ:
   Health app ⟵ תמונת הפרופיל ⟵ **Export All Health Data** ⟵ מייצא קובץ zip.
   מחלצים ממנו את `export.xml` ומעלים אותו במסך **היסטוריה ⟵ ייבוא היסטוריה** —
   האפליקציה תמצא בתוכו את כל ימי הוסת שנרשמו ותשלים איתם את ההיסטוריה.

## מבנה נתונים

מסד SQLite מקומי (`cyclesync.db`, נוצר אוטומטית, לא נכנס לגיט) עם שלוש טבלאות:
ימי וסת, יומן פידבק יומי (מצב רוח/אנרגיה/תיאבון/הערה), והגדרות.

## חישוב שלבי המחזור

השלבים (וסת/פוליקולרי/ביוץ/לוטאלי) מחושבים מאורך המחזור והוסת הממוצעים שלך בפועל
(מתעדכן אוטומטית ככל שמתעד/ת יותר מחזורים), לפי המודל הרפואי הסטנדרטי: שלב הביוץ
מוערך כ-14 יום לפני תחילת הוסת הבאה. אלו הערכות סטטיסטיות ולא אבחון רפואי.

## טכני

- Node.js + Express, נתונים ב-SQLite (`node:sqlite` המובנה, בלי תלות חיצונית)
- Frontend: HTML/CSS/JS פשוטים (בלי build step), גרפים עם Chart.js
- פורט: 3778 (ניתן לשנות עם משתנה סביבה `PORT`)
