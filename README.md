# 🏷️ PriceWatch — השוואת ומעקב מחירים בישראל

כלי עצמאי שרץ על המחשב שלך: מחפשים מוצר (ברקוד / מק״ט / שם / תמונה), רואים בכמה הוא נמכר בכל החנויות בישראל ממוין מהזול ליקר, שומרים למעקב — והכלי סורק אוטומטית ושולח התראה במייל/ווטסאפ כשהמחיר יורד.

## הפעלה

לחיצה כפולה על **`start-pricewatch.bat`** — נפתח דפדפן בכתובת http://localhost:3777

## הפעלה אוטומטית עם Windows (מומלץ!)

לחיצה כפולה על **`install-autostart.bat`** — פעם אחת בלבד.
מעכשיו PriceWatch ירוץ ברקע בכל הדלקת מחשב, הסריקות האוטומטיות יעבדו והממשק תמיד יהיה זמין ב-http://localhost:3777 (בלי חלון שחור).

להסרה: מחיקת `PriceWatch.lnk` מתיקיית ה-Startup (הנתיב מוצג בעת ההתקנה).

## 🌍 הקישור הקבוע: https://wolfprices.com

**כתובת קבועה לנצח** — לא מתחלפת, עובדת מכל מקום בעולם, לכל מכשיר.

- מופעלת דרך מנהרת Cloudflare בשם (`pricewatch`) המחוברת לדומיין wolfprices.com
- קוד כניסה: מוגדר בהגדרות ← "קוד כניסה משותף" (משתפים קישור + קוד רק עם מי שרוצים)
- בנייד: אחרי הכניסה — "הוספה למסך הבית" לקבלת אייקון אפליקציה
- ברשת הביתית תמיד עובד גם: http://192.168.10.3:3777
- התנאי היחיד: המחשב הזה דולק (המערכת רצה עליו)
- הדומיין מתחדש אוטומטית כל שנה (~$10.46) דרך חשבון Cloudflare הרשום

### רכיבי המנהרה הקבועה
- הגדרה: `C:\Users\Lenovo\.cloudflared\config.yml` · מנהרה: `pricewatch`
- מופעלת אוטומטית ע"י `tunnel.js` בעליית השרת (נבדק ששורד הפעלה מחדש)

## 📱 שימוש מהטלפון הנייד

הממשק מותאם מלא לנייד. כדי לגשת מהטלפון (באותה רשת WiFi):

1. פעם אחת: קליק ימני על **`enable-phone-access.bat`** ← Run as administrator (פותח את פורט 3777 ברשת הביתית בלבד)
2. גולשים מהנייד לכתובת שמופיעה בטאב ⚙️ הגדרות ← "גישה מהטלפון הנייד" (למשל http://192.168.10.3:3777)
3. בתפריט הדפדפן בנייד: **"הוספה למסך הבית"** — ו-PriceWatch יופיע כאפליקציה עם אייקון משלה

הסריקות והשמירות מסונכרנות — זה אותו כלי, מכל מכשיר.

## מקורות המחירים

| תחום | מקור | כיסוי |
|---|---|---|
| מזון, פארם, טואלטיקה | chp.co.il (נתוני חוק שקיפות המחירים) | כל הרשתות: שופרסל, רמי לוי, קרפור, ויקטורי, יוחננוף, טיב טעם, גוד פארם ועוד — סניפים באזורך + חנויות אונליין, כולל מבצעים |
| סופר-פארם (חסרה ב-CHP) | חיבור ישיר לאתר שלהם (adapters/superpharm.js) | התאמה לפי ברקוד מדויק; תרופות לא נמכרות אונליין ולכן לא יופיעו |
| אלקטרוניקה, סלולר, חשמל, צרכנות | זאפ (דרך דפדפן סמוי) | עשרות חנויות: באג, איי-סל, הצלצול ועוד |
| חנויות בחיבור ישיר | `adapters/stores.js` | KSP, מחסני חשמל, שקם אלקטריק, באג, גוד פארם, אופיס דיפו, LastPrice, ACE, עולם הקולנוע והחשמל, איבורי, אלם (11 חנויות) |

## 🧠 חיפוש חכם (`adapters/query.js`)

השם שמוקלד לא חייב להיות מדויק — המערכת משלימה לבד:

| מה שהוקלד | מה שנמצא |
|---|---|
| `אייפון 16` | iPhone 16 |
| `xiomi band` (תקלדה) | Xiaomi Smart Band 10 |
| `mi band 10` | Smart Band 10 (כינוי מסחרי אחר) |
| `tcyhj` (מקלדת בעברית) | אבטיח |
| `ןפיםמק` (מקלדת באנגלית) | iPhone |

המנגנון: תיקון פריסת מקלדת → מילון מותגים וקטגוריות עברית↔אנגלית → כינויי קווי מוצר →
התאמה מטושטשת עם סובלנות לתקלדות. אם הניסוח המקורי לא הניב תוצאות, המערכת מנסה
וריאציות בזו אחר זו ומודיעה למשתמשת באיזה ניסוח נמצאו התוצאות.

> ⚠️ **חשוב — הדפדפן של Playwright**: חלק מהחנויות (KSP, עולם הקולנוע, אלם, זאפ) נסרקות דרך דפדפן רקע.
> אם משדרגים את `playwright`/`@playwright/test`, **חובה** להריץ אחר כך:
> ```bash
> npx playwright install chromium                              # לנתיב ברירת המחדל
> $env:PLAYWRIGHT_BROWSERS_PATH="0"; npx playwright install chromium   # ולנתיב הפרויקט
> ```
> בלי זה החנויות האלה יחזירו שגיאה — והמערכת תדווח שהן נבדקו ונכשלו (ולא ש"אין מלאי").

## תזמון והתראות

לכל מוצר במעקב בוחרים: תדירות סריקה (שעה / 3 / 6 / 12 שעות / יום / שבוע), מתי להתריע (ירידת מחיר / כל שינוי / מחיר יעד), והכלי משווה כל סריקה לקודמתה.

## 🧪 בדיקות

```bash
npm run check                 # בדיקת תחביר
npm test                      # בדיקות רגרסיה + אבטחת API (25 בדיקות)
npm run test:e2e              # בדיקות E2E בדפדפן (18 בדיקות)
```

קוד הכניסה לבדיקות מגיע ממשתנה סביבה בלבד — לעולם לא מהקוד:

```bash
$env:TEST_ACCESS_CODE="<הקוד>"; npm test
```

בדיקות ה-API וה-E2E מדלגות על עצמן אם המשתנה חסר, כדי שהרצה מקומית לא תישבר.
הבדיקות אינן שולחות מיילים/וואטסאפ אמיתיים ואינן מוחקות מוצרים במעקב.

## ⚙️ מצבי פריסה

| משתנה סביבה | ערך | משמעות |
|---|---|---|
| `PRICEWATCH_MODE` | `hosted` (ברירת מחדל) | אתר ציבורי — לא מוצגות כתובות רשת פנימיות או הוראות LAN, והעוגייה מסומנת `Secure` |
| `PRICEWATCH_MODE` | `local` | הרצה ביתית — מוצגות גם כתובות הרשת המקומית |
| `PRICEWATCH_DEFAULT_PIN` | מחרוזת | קוד הכניסה ההתחלתי (עד לשינוי הראשון דרך הממשק) |

## 🔒 אבטחה

- סודות (סיסמת אפליקציה, מפתחות API, קוד הכניסה) **לעולם אינם נשלחים ללקוח** — ה-API מחזיר רק דגלי `configured`.
- שמירת הגדרות ללא הזנת סוד חדש **אינה מוחקת** את הסוד הקיים (עדכון חלקי).
- שינוי קוד הכניסה דורש את הקוד הנוכחי + הקלדה כפולה, ומנתק מיד את כל המכשירים.
- הגבלת קצב על ניסיונות כניסה (8 בחלון של 15 דקות, נעילה הדרגתית).
- קוד ה-QR מכיל **רק את כתובת האתר** — אף פעם לא קוד כניסה או טוקן.
